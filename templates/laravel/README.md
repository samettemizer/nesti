# Webservice

This Laravel application serves only the API. It renders no user interface:
the UI lives in a separate single-page application that talks to this API.

## Setup

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
php artisan db:seed
```
