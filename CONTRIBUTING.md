# Contributing

Improvements and documentation contributions are welcome.

## Pull requests

- Keep changes small and consistent with the existing project.
- Briefly explain what changed and how you checked it.
- Use the commit format below for all commits in your PR.

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/); [Commitizen](https://commitizen-tools.github.io/commitizen/) can help but is optional.

```text
<type>(<optional scope>): <short description>
```

Allowed types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.

```text
feat(generic): add task clarification
fix(python): prevent duplicate reviewer handoffs
docs: clarify plugin installation
```
